# トーナメント表メーカー

テニスのダブルス大会向けに、部門ごとのトーナメント表と、全部門をまとめた試合進行表を作って印刷するWebページです。サーバーは不要で、`index.html` をブラウザで開くと使えます。

## できること

- 部門ごとにトーナメント表を作る
  - 最初は「男子低学年・男子中学年・男子高学年・女子低学年・女子中学年・女子高学年」の6部門。「部門を編集」で名前の変更・追加・削除ができる
  - 参加チームを「チーム名・所属・シード」で入力して、組み合わせを自動で作る
  - 同じ所属のチームが、なるべく遅い回戦まで当たらないように配置する（1回戦の同所属対戦は、避けられない場合だけ警告を表示する）
  - シードは複数チームに設定でき（入力欄の上から第1シード、第2シード…）、標準位置に置き、BYE（1回戦不戦勝）は上位シードから割り当てる
  - チーム名を2つ続けて押すと位置を入れ替えられる
  - 準決勝が2試合とも行われる部門は3位決定戦、準々決勝が4試合とも行われる部門は5〜8位決定戦（5〜8位決定戦2試合のあと、5位決定戦と7位決定戦）も作る
- 全部門の試合進行表（対戦順・時刻・コート・審判）を自動で作る
  - 空いたコートには、どの部門でも始められる試合を入れる。まだ始まっていない部門と、後に続く試合の多い試合を先に入れる
  - 5〜8位決定戦は、その部門の決勝と3位決定戦のあとにする
  - 試合番号は全部門の通し番号で、対戦順・コート順に振る
  - 審判は同じ部門から出す
    - 最初（敗者がまだいない時間）は、BYE のチームや試合が先のチーム
    - そのあとは前に終わった試合の敗者（同じコートの直前の試合を優先）
    - 準々決勝（設定で準決勝にもできる）からは、負けた2チームから1人ずつ
    - 決勝と3位決定戦は準々決勝の敗者から1人ずつ、5〜8位決定戦は決勝・3位決定戦に出たチームから1人ずつ
  - 審判を出せるチームが同じ部門にいない時間には、その部門の試合を入れない（2つの時間枠まで）
  - 自動で作ったあと、マスを2つ続けて押すと試合の位置を入れ替えられる。時刻と審判は表の上で書き換えられる
- A4横で印刷する
  - トーナメント表は1部門1ページ。各試合に試合進行表の審判・時間・コートを表示する（空欄にして手書き用にもできる）
  - 試合進行表は1ページにコート4面ずつ
- データはブラウザに自動保存される。「ファイルに保存」で JSON ファイルに書き出し、別のパソコンで読み込める（部門のない以前の形のファイルは「男子低学年」に読み込む）
