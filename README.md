# トーナメント表メーカー

テニスのダブルス大会（20ペア程度）向けに、トーナメント表と試合進行表を作って印刷するWebページです。サーバーは不要で、`index.html` をブラウザで開くと使えます。

## できること

- 参加ペアを「ペア名, 所属, シード」の形で貼り付けて、組み合わせを自動で作る
  - 同じ所属のペアが、なるべく遅い回戦まで当たらないように配置する（1回戦の同所属対戦は、避けられない場合だけ警告を表示する）
  - シードは標準位置に置き、BYE（1回戦不戦勝）は上位シードから割り当てる
  - ペア名を2つ続けて押すと位置を入れ替えられる
- 試合進行表（時刻・コート・審判）を自動で作る
  - 試合番号は時刻順に振る
  - 審判は前に終わった試合の負けたペア。負けたペアがいない時間は、BYE のペアや試合が先のペアを割り当てる
  - 自動で作ったあと、表の上で手直しできる
- A4横で、トーナメント表と試合進行表を印刷する
- データはブラウザに自動保存される。「ファイルに保存」で JSON ファイルに書き出し、別のパソコンで読み込める
