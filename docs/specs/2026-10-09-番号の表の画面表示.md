# 番号の表を本体の画面にも表示する

## 目的
今は印刷でしか見られない「番号の表」（チーム名を出さず番号だけの試合進行表）を、本体の試合進行表の画面でも見られるようにする。

## やること
- 試合進行表の画面に「表示：詳しい表／番号の表」の切り替えを付ける。
- この切り替えと、印刷パネルの「試合進行表の形式」（`#printStyleInput`）を1つにまとめる。値は既存の `state.schedule.settings.printStyle`（`'compact'`／`'detail'`）をそのまま使い、画面で選んだ形式がそのまま印刷される。
  - 印刷パネルの選択欄は削除し、説明文（`#printPanel` の `.help`）を合わせて直す。
  - 既存の初期値は `'compact'`。画面の初期表示も保存値に従う。
- 「番号の表」を選んだときは、`L.compactSchedule` と `compactTableHtml` を使い、印刷と同じ内容（順・コートごとの対戦番号・審判）を画面に表示する。
  - 画面ではページ分け（15行ごと・4コートごと）をせず、全時間枠・全コートを1つの表で出す。
  - コートが多いときは表を横スクロールにする（ページ全体は横スクロールさせない）。
- 番号の表を表示している間は編集できない。「試合の入れ替えや時刻・審判の書き換えは『詳しい表』に切り替えて行ってください。」の一言を表示し、詳しい表の操作説明（`#gridHelp`）は隠す。
- 番号の表の表示中は、マスのクリック（入れ替え）や入力のイベントが反応しないようにする（`selectedCell` も解除する）。

## やらないこと
- 保存データの形の変更（`validateState` は触らない）。
- 番号の表の中身（`compactSchedule` の出力）の変更。
- 印刷のページ分け・用紙の向きの変更。

## 触るファイル・関数
- `index.html`：試合進行表の画面に切り替えを追加、印刷パネルの選択欄と説明文を整理。
- `js/app.js`：`renderSchedule`、`printStyleInput` 関係（設定の読み込み・保存・`change` イベント）、`scheduleArea` のクリック／入力イベント。`compactTableHtml` は画面用でも使えるように再利用する（コード規約は ES5 風）。
- `css/style.css`：画面用の番号の表のスタイル（印刷用の mm 指定の幅が画面で崩れないようにする）、横スクロール。

## 確認方法
- `for f in js/*.js test/*.js; do node --check "$f"; done` と `npm test` が通る。
- ブラウザで日程を自動作成し、切り替えで「詳しい表」「番号の表」が入れ替わる。番号の表で名前が出ない。
- 番号の表の表示中にマスをクリックしても入れ替わらない。
- 切り替えた形式で印刷され、再読み込み後も選択が残る。
- スマホ幅でページ全体が横スクロールしない。
